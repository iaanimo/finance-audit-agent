# 发票 PDF 文本层抽取（确定性路径，不联网）

# letter-spacing 时，新版会把字与字之间抽成一个空格，字段抽取会静默失效。
# 抽取层已按「容忍字间距」加固（见 finance/extractor.py 的 _RE_LETTER_SPACED），
# 上界是第二道保险 —— 别让依赖随 pip 自由漂移。
pypdf>=4.0.0,<7.0.0

# 测试框架 —— README 里让你跑 pytest，所以它必须是明示依赖，
# 否则别人 clone 下来照 README 操作会直接报 No module named pytest。
pytest>=7.4

# .env 支持（可选，缺了也能跑）
python-dotenv>=1.0.0
